AnotherCC 1.0 - бесплатный ИИ-помощник для программирования (как Claude Code, в терминале)
==========================================================================================

ЧТО ЭТО
Агент, который сам читает ваш проект, правит файлы, запускает команды и тесты, ищет баги.
Мозг - бесплатные модели через API (OpenRouter, Groq, Gemini, Cerebras) или локальная Ollama.
Честно: качество зависит от выбранной модели. Бесплатные модели слабее Claude, но с
инструментами агента справляются с большинством повседневных задач.

БЫСТРЫЙ СТАРТ
1. Нужен Python 3.8+ (https://python.org, при установке поставьте галочку "Add Python to PATH").
2. Получите бесплатный ключ, например OpenRouter: https://openrouter.ai/keys
3. Откройте терминал в папке вашего проекта и запустите AnotherCC.exe
   (или перетащите AnotherCC.exe в окно терминала и нажмите Enter).
4. При первом запуске выберите провайдера и вставьте ключ. Дальше просто пишите задачу:
   > добавь в проект тесты для parser.py и запусти их

ПОЛНОСТЬЮ АВТОНОМНЫЙ .EXE (без Python у других людей)
Запустите build_standalone_exe.bat - он соберёт AnotherCC-standalone.exe через PyInstaller.
Этот файл работает на любом Windows 10/11 без установленного Python.

КОМАНДЫ ВНУТРИ
  /help  /setup  /models  /model <имя>  /auto  /clear  /cd <папка>  /exit
  Несколько строк: начните и закончите сообщение строкой """
  Ctrl+C - прервать текущую задачу.

ЗАПУСК С ПАРАМЕТРАМИ
  AnotherCC.exe -p "объясни, что делает этот проект"     разовая задача
  AnotherCC.exe -y                                        без вопросов о правках и командах (осторожно!)
  AnotherCC.exe -m openai/gpt-oss-120b:free               выбрать модель

БЕЗОПАСНОСТЬ
Перед записью файлов и запуском команд программа спрашивает разрешение (y / a / n).
Чтение, поиск и просмотр папок идут без вопросов. Агент работает в той папке, где запущен.

ПОЛЕЗНО
- Бесплатные модели меняются. Команда /models показывает актуальный список (бесплатные с *).
- Модель по умолчанию на OpenRouter: openrouter/free - сам выбирает свободную бесплатную модель.
- Файл ANOTHERCC.md (или CLAUDE.md / AGENTS.md) в папке проекта читается как инструкции.
- Настройки: %USERPROFILE%\.anothercc\config.json. Ключ можно задать переменной ANOTHERCC_API_KEY.
- Бесплатные тарифы имеют лимиты: при ошибке 429 программа сама повторяет запрос.
